# The Creator Blueprint — Next.js recreation

A responsive Next.js/React recreation of the public Creator Blueprint landing page.

## Run locally

1. Install Node.js 18.17+.
2. In this folder run `npm install`.
3. Run `npm run dev` and open http://localhost:3000.
4. Run `npm run build` to create a production build.

## Notes
- The page structure, copy, price, modules, FAQ, and checkout destination are based on the publicly accessible source page.
- The visual assets are referenced from the source site's public Framer CDN. For a production deployment, confirm you have permission to reuse those assets or replace them with licensed originals.
- The original checkout destination is retained. The newsletter form and member login are not wired to a backend.
- This is a high-fidelity independent recreation, not the original Framer source. Exact pixel parity requires the original site's source design tokens, fonts, responsive breakpoints, and all original assets.
